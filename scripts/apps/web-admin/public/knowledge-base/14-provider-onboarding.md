# Provider Onboarding & Compliance

Service Providers (Nurses, PSWs, Physios) are the lifeblood of the care delivery.

## Unified Verification
When a provider applies to work for a Child Agency, the system requires standard documentation (e.g., License numbers, Background Checks, Immunization records, Vitals Training).

## Hard-Coded Expirations
The Platform HQ enforces strict expiration logic algorithmically. 

If a nurse's tuberculosis test expires at midnight on Friday, the platform physically blocks the Auto-Pilot from assigning them shifts on Saturday morning. This completely eliminates manual human error in compliance tracking, protecting the Master Franchise's hospital contracts from catastrophic audit failures.
