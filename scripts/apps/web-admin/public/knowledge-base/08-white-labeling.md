# White-Labeling & Brand Customization

Master Franchisees need their localized hospitals and nurses to trust *them*, not PrimeCare HQ.

## The Illusion of Ownership
The White-Label engine built into the platform allows the Root Tenant to:
*   Upload their own primary and secondary corporate logos.
*   Define CSS primary, secondary, and accent color schemes that propagate through the entire UI components.
*   Map their own Custom CNAME Domain (e.g., `portal.apexcare.com`).

To the end patient facing the Care Plan, and the nurse opening the mobile app, PrimeCare HQ is entirely invisible. It is a 100% ApexCare experience, powered quietly by PrimeCare rails.
