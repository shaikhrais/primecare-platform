# Temporary workspace

Keep this directory for maintained governance utilities that write temporary SQL
files here. Its generated contents are ignored by Git. Reusable utilities belong
under `scripts/` or `tools/`.

The 279 historical scratch files were retired with exact source preservation and
per-file records in `docs/refactoring/file-retirement-batch3/`. Recovery archive:
`PrimeCare_Retired_Utilities_And_Exports.zip`; pinned source commit:
`f787038bc0b134d94c157e4849585d1d33754528`.
