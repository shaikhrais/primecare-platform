# Generate Territory Pitch (tsk_usbd_01)

## Action Name:
Generate Lead Pitch Deck

## Steps
1. Navigate to 'Prospects' tab.
2. Select an active B2B prospect.
3. Click "Generate Pitch Deck".
4. Review auto-populated demographic data and hit "Send".
