# File SOAP Note (tsk_cli_rmt_01)

## Action Name:
Submit Post-Treatment SOAP Note

## Steps
1. Navigate to patient's active appointment.
2. Click "Add SOAP Note".
3. Fill Subjective, Objective, Assessment, and Plan fields.
4. Sign electronically and submit.
