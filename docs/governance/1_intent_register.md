# Intent Register

*This document serves as the master list of every feature and its explicit business goal. If a feature is in the code but not here, it is uncontrolled.*

## 1. User Management

| Feature | Business Goal |
| :--- | :--- |
| **Create User** | Allow administrators to onboard new staff, set initial credentials, and assign basic facility access. |
| **Edit User** | Allow administrators to update user profiles, metadata, and contact info after onboarding. |
| **Deactivate User** | Prevent former employees from accessing the system while retaining historical audit logs of their actions. |
| **Reset Password** | Enable users to regain access securely if credentials are forgotten. |
| **Role Permissions** | Ensure users can only access screens and data relevant to their exact department and clearance level. |
