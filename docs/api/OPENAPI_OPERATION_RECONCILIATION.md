## Logout comment reconciliation

`POST /v1/auth/logout` accepts optional credentials. The auth specification lists an empty security requirement object alongside bearer and cookie alternatives. The auth work-package specification uses an empty security array. Both allow a request without credentials. The Worker invalidates only a presented token, then clears the session cookie on success. See the [auth specification](../auth-openapi.json), [work-package contract](auth-delivery-work-package.openapi.json) and [Worker handler](../../cloudflare/workers/src/auth.ts).
