# PrimeCare Training Documentation

This directory contains learner-facing guides and reviewed training templates. Documentation is **not automatically published** into the Academy or Help application.

## Start here

- [Your role, purpose and how to execute work in PrimeCare](role-purpose-and-system-intents.md) — company purpose, role boundaries, daily workflow, screen intents, escalation and the required per-role training template.

- [PSW training design reference](psw-training-preview.html) — device wizard, daily practice and task library. [Integration requirements](psw-training-integration.md) document the existing screen and release gates.

## Publishing checklist

Before showing role-specific material to a user, verify the authoritative role and tenant, approved job duties, existing screen/section/element/API mappings, localization, training ownership, and actual Academy/Help content publication. Do not infer completion or permission from a document or visible screen.
