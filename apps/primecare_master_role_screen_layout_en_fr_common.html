PrimeCare Master Role, Screens, Base Screens, EN/FR, and Layout Structure

Enterprise healthcare SaaS structure for founder, franchise, clinical, support, marketing, and client roles across mobile, tablet, and desktop layouts.

Global Layout Rules

Mobile = Single Column Action
Tablet = Two Column Workspace
Desktop = Sidebar + Multi Panel
Flow = Role → Screens → Device Layout

Language Support (EN / FR)

EN = English
FR = Français
Bilingual Labels via i18n
Common Base Screens for All Roles

All core navigation labels, buttons, menus, alerts, forms, and shared modules should support both English and French. The role-specific content can change, but the shared structure should remain consistent across languages.

Base Screens / Common Screens for All Users

Shared foundation pages that every role should have, with different permissions and content depending on the user type.

Common Screens

  • Dashboard
  • Profile
  • Notifications
  • Messages
  • Schedule / Calendar
  • Documents / Files
  • Settings
  • Help / Support

Why These Are Shared

  • Dashboard gives each user a home page after login
  • Profile lets each user manage their own account information
  • Notifications keeps everyone aware of updates and alerts
  • Messages supports communication between staff, management, and clients
  • Schedule is needed in different ways by almost every role
  • Documents stores files, reports, forms, and references
  • Settings manages password, language, and preferences
  • Help / Support gives a clear path for issues and questions

Layout Explanation

Mobile
  • Single-column action-first layout
  • Best for fast tasks and field work
  • Large buttons, stacked cards, short forms
Tablet
  • Two-column workspace layout
  • Left side usually shows info, right side shows actions or forms
  • Best for review + input together
Desktop
  • Sidebar + topbar + multi-panel workspace
  • Best for reporting, analytics, large tables, and multi-step workflows
  • Shows more data at the same time
