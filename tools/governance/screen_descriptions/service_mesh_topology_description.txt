User Work List:
1. Monitor the service mesh topology for active nodes and routes.
2. Refresh the topology data using the refresh button.
3. Identify any errors in loading the topology data.
4. Analyze the interactive network graph component for insights on service routing.

Red Flags of Operation:
1. Failure to load mesh topology data, indicated by error messages.
2. A significant number of inactive nodes or routes, which may suggest issues in the service mesh.
3. Long loading times for the topology data, which could indicate performance problems.
4. Inconsistent data displayed in the interactive network graph.

Dashboard Requirements:
1. Display active nodes and routes count prominently.
2. Show loading status and error messages clearly.
3. Include a refresh button for real-time data updates.
4. Provide visual indicators for performance metrics (e.g., loading times, error rates).
5. Integrate an interactive network graph to visualize service routing effectively.
