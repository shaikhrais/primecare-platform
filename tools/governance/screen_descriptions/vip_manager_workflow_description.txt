VIP Client Manager Responsibilities:
1. Oversee compliance workflows for VIP clients.
2. Execute task scans to ensure compliance.
3. Monitor operational telemetry and logs.
4. Manage and update the dashboard with relevant metrics.
5. Respond to and resolve any compliance issues.
6. Communicate with stakeholders regarding compliance status.
7. Maintain documentation of compliance activities.
8. Analyze trends in compliance data to identify areas for improvement.

Red Flags of Operation:
1. Increased error rates in compliance scans.
2. Delays in executing task scans.
3. Unresolved compliance issues persisting over time.
4. Lack of communication from team members regarding compliance updates.
5. Significant deviations in operational metrics from established benchmarks.
6. Frequent network or API errors during compliance checks.
7. Negative feedback from stakeholders regarding compliance processes.

Dashboard Requirements for VIP Client Manager:
1. Overview of compliance status (e.g., clear, exceptions flagged).
2. Real-time operational telemetry metrics.
3. Logs of recent compliance activities and actions taken.
4. Alerts for any compliance issues or errors.
5. Historical data trends for compliance metrics.
6. Action buttons for executing compliance scans and other tasks.
7. Visual representations of data (charts, graphs) for quick insights.
8. User activity logs for accountability and tracking.
