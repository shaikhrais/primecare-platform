List of work the user must do:
1. Monitor the status of the Cto Verification Hub.
2. Review and verify the data presented on the screen.
3. Address any errors that may arise during data loading.
4. Ensure the application is functioning as expected.

Red flags of operation:
1. Frequent loading errors indicating potential issues with data retrieval.
2. Long loading times that may suggest performance bottlenecks.
3. Inconsistent data displayed on the screen.
4. Lack of user feedback or unclear error messages.

What is needed on the dashboard of the user:
1. Real-time status indicators for data loading and verification processes.
2. Error logs or alerts for any issues encountered during operation.
3. Performance metrics to track loading times and responsiveness.
4. User feedback options to report issues or suggest improvements.
