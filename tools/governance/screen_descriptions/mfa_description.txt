User Work List:
1. Enter the 6-digit code from the authenticator app.
2. Validate the entered code.
3. Submit the code for verification.
4. Review the verification result.

Red Flags of Operation:
1. User enters an incorrect code.
2. Code is not exactly 6 digits.
3. User experiences loading delays during verification.
4. Error messages are displayed without clear guidance.

Dashboard Needs:
1. Display user verification status (verified or not).
2. Show error messages if the verification fails.
3. Indicate loading status during code verification.
4. Provide a history of previous verification attempts (if applicable).
