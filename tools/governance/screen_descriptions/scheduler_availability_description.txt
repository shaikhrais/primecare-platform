User Work List:
1. Manage institutional settings.
2. Track real-time clinical workflows.
3. Verify live compliance standing.
4. Monitor operational status and SLA uptime.
5. Conduct verification audits.
6. Analyze hourly transaction flow.
7. Submit secure operational event logs.

Red Flags of Operation:
1. Operational status not marked as ACTIVE.
2. SLA uptime drops below acceptable thresholds.
3. Compliance issues detected during verification audits.
4. Significant fluctuations in hourly transaction flow.
5. Delays or failures in submitting secure operational event logs.

Dashboard Needs:
1. Display current operational status and SLA uptime.
2. Show compliance status and any detected issues.
3. Provide a visual representation of transaction flow over time.
4. Include a form for submitting operational event logs with necessary fields.
5. Offer insights or alerts for any red flags identified in operations.
