User Tasks:
1. Enter their email address in the input field.
2. Click the "SEND RECOVERY LINK" button to submit the request.
3. Check their email for recovery instructions.

Red Flags of Operation:
1. If the email field is empty or invalid, the user should be informed with an error message.
2. If the submission fails, an appropriate error message should be displayed.
3. If the user does not receive an email after submission, it may indicate a backend issue or incorrect email.

Dashboard Needs:
1. Display the current state of the password recovery process (loading, success, error).
2. Show any error messages related to the email input or submission.
3. Provide a confirmation message when recovery instructions are sent successfully.
