User Work List:
1. Monitor IoT event notifications.
2. Dispatch broadcast alerts for IoT events.
3. Resolve IoT events as necessary.
4. Review console logs for system status and alerts.
5. Manage and select severity levels for alerts.
6. Select nodes for event dispatching.
7. Review metrics on active broadcasts and resolved alerts.

Red Flags of Operation:
1. High number of unresolved IoT events indicating potential system issues.
2. Frequent critical alerts suggesting underlying problems with monitored equipment.
3. Delays in dispatching alerts could indicate communication issues.
4. Errors in loading IoT events from the API may signify backend problems.
5. Inconsistent data in console logs could indicate system malfunctions.

Dashboard Needs:
1. Real-time metrics on active and resolved IoT events.
2. Alerts summary with severity breakdown.
3. Console log display for system diagnostics.
4. Event dispatching form for creating new alerts.
5. Historical timeline of dispatched events for auditing.
6. Node selection dropdown for targeted alerts.
7. Visual indicators for system health and performance.
