User Work List:
1. Run Compliance Scan
2. Sync Posture
3. Update Policy
4. Export Logs
5. Trigger State Action
6. Add Log Entry
7. Manual Refresh of Dashboard

Red Flags of Operation:
1. System Loading State: Indicates ongoing processes that may delay user actions.
2. Error Messages: Any error displayed should be addressed immediately.
3. Compliance Audit Results: If any governance invariants are not validated, it requires urgent attention.
4. Manual Synchronization: If frequent manual syncs are needed, it may indicate underlying issues.
5. Log Entries: Unusual or excessive log entries may signal operational problems.

Dashboard Needs:
1. Title and Description: Clear identification of the dashboard purpose.
2. Operational Metrics: Display of active operations and security clearance levels.
3. Telemetry Charts: Visual representation of core telemetry data over time.
4. Audit Logs: A section to review operational audit logs with timestamps.
5. Action Buttons: Quick access buttons for executing compliance scans and other actions.
6. Loading Indicators: Visual cues for ongoing processes to manage user expectations.
