User Work List:
1. Monitor error rates and identify trends.
2. Assess test coverage and ensure it meets project standards.
3. Analyze mean time to recovery (MTTR) for incidents.
4. Track uptime to ensure system reliability.
5. Review recent QA audit logs for insights on testing outcomes.

Red Flags of Operation:
1. High error rates indicating potential issues in the system.
2. Low test coverage suggesting inadequate testing practices.
3. Increased MTTR pointing to delays in incident resolution.
4. Decreased uptime affecting user experience and trust.
5. Frequent failures in QA audit logs signaling potential quality issues.

Dashboard Needs:
1. Real-time display of key metrics (error rate, test coverage, MTTR, uptime).
2. Visual indicators for trends (e.g., graphs or color coding).
3. Recent audit logs with timestamps and outcomes.
4. Refresh button for updating metrics.
5. Error handling messages for failed data loads.
