User Work List:
1. View active marketing campaigns.
2. Refresh campaign data.
3. Create new campaigns.
4. Monitor campaign performance metrics such as spend, clicks, and conversions.

Red Flags of Operation:
1. Failure to load campaign data, indicated by an error message.
2. Long loading times when fetching campaign data.
3. Inconsistent or missing campaign performance metrics.
4. Campaigns with low clicks or conversions relative to spend.

Dashboard Requirements:
1. Display active marketing campaigns with relevant details (name, platform, status).
2. Show performance metrics (spend, clicks, conversions) for each campaign.
3. Provide a refresh button to update campaign data.
4. Include a button to create new campaigns.
5. Indicate loading states and error messages clearly.
