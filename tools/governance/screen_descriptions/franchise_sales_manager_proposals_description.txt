User Tasks:
1. Review franchise proposals submitted by potential franchisees.
2. Analyze the financial viability of each proposal.
3. Communicate with franchisees regarding their proposals.
4. Approve or reject proposals based on established criteria.
5. Track the status of each proposal in the system.
6. Generate reports on proposal outcomes and franchise performance.

Red Flags of Operation:
1. Delays in proposal review and feedback.
2. High number of rejected proposals indicating potential issues in the application process.
3. Lack of communication with franchisees leading to dissatisfaction.
4. Inconsistent criteria for proposal approval/rejection.
5. Inability to track proposal status effectively.
6. Frequent errors in financial analysis leading to poor decision-making.

Dashboard Requirements:
1. Overview of all submitted proposals with status indicators (pending, approved, rejected).
2. Metrics on average review time for proposals.
3. Communication logs with franchisees.
4. Financial analysis summary for each proposal.
5. Reports on trends in proposal approvals and rejections.
6. Alerts for proposals that are overdue for review.
