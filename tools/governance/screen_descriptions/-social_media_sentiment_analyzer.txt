User Tasks:
1. Monitor social media sentiment for various platforms.
2. Refresh sentiment data using the refresh button.
3. Analyze brand sentiment overview based on positive, neutral, and negative indicators.
4. Identify trends in sentiment data over time.

Red Flags of Operation:
1. Frequent errors when fetching sentiment data.
2. Long loading times when retrieving data.
3. Inconsistent sentiment data across different platforms.
4. Low engagement or response rates on social media posts.

Dashboard Needs:
1. Real-time sentiment data display.
2. Visual indicators for positive, neutral, and negative sentiment.
3. Historical sentiment trends for analysis.
4. Alerts for significant changes in sentiment.
5. User-friendly interface for easy navigation and understanding of data.
