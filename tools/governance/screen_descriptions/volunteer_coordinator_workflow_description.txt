List of work for volunteers:
1. Execute action tasks using designated buttons.
2. Monitor and manage workflow operations.
3. Participate in integration sandbox activities.
4. Refresh and update dashboard information.
5. Collaborate with other coordinators and staff.

Red flags of operation:
1. Lack of engagement or participation from volunteers.
2. Delays in executing action tasks.
3. Inconsistent updates on workflow progress.
4. Poor communication among team members.
5. Technical issues with the dashboard or workflow tools.

Dashboard needs for volunteers:
1. Real-time updates on task status and progress.
2. Notifications for upcoming tasks and deadlines.
3. Performance metrics and analytics for individual and team contributions.
4. Communication tools for collaboration and feedback.
5. Access to resources and training materials for skill development.
