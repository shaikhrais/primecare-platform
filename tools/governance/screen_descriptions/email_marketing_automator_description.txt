User Tasks:
1. View active email journeys.
2. Refresh the list of email journeys.
3. Create a new email journey.
4. Toggle the active status of an email journey.
5. Monitor key metrics such as sent count, open rate, and click-through rate (CTR).

Red Flags of Operation:
1. Frequent errors when loading email journeys indicating potential API issues.
2. Low open rates or CTRs suggesting ineffective email content or targeting.
3. High number of inactive journeys which may indicate lack of engagement or relevance.
4. Delays in loading data which could affect user experience.

Dashboard Needs:
1. Summary of active journeys with key metrics (sent, open rate, CTR).
2. Notifications for errors or issues with journeys.
3. Visual indicators for performance trends over time.
4. Quick access buttons for creating new journeys and refreshing data.
5. Filters to sort or categorize journeys based on performance metrics or audience.
