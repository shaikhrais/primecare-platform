User Tasks:
1. View active policy exemptions.
2. Refresh the list of policy exceptions.
3. Revoke an exception if necessary.
4. Extend the expiration of an exception if needed.
5. Review details of each exception, including justification and approver.

Red Flags of Operation:
1. Loading errors when fetching data from the API.
2. Lack of justification for policy exceptions.
3. Expired exceptions that have not been addressed.
4. High number of exceptions requested by a single user.
5. Exceptions without an approver listed.

Dashboard Needs:
1. Summary of active policy exemptions.
2. Notifications for exceptions nearing expiration.
3. Quick access buttons for revoking or extending exceptions.
4. Visual indicators for exceptions with missing justifications or approvers.
5. Search and filter options for easier navigation of exceptions.
