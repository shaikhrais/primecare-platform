User Tasks:
1. Monitor patient retention rates.
2. Analyze churn prediction and lifetime value (LTV).
3. Refresh data to get the latest analytics.
4. Review cohort analysis for insights on patient behavior.

Red Flags of Operation:
1. High churn rates indicating potential issues with patient satisfaction or service quality.
2. Low average lifetime value (LTV) suggesting that patients are not engaging with services long-term.
3. Frequent errors when loading analytics data, which may indicate backend issues or API failures.

Dashboard Requirements:
1. Display overall retention rate with a visual representation (e.g., circular progress indicator).
2. Show average lifetime value (LTV) prominently.
3. Include a refresh button for real-time data updates.
4. Provide a placeholder for cohort analysis to visualize patient trends over time.
5. Error handling to inform users of any issues in data retrieval.
