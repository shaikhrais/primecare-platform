User Work List:
1. Monitor core operational KPIs.
2. Refresh metrics data.
3. Compare operational metrics across different periods.
4. Analyze trends in operational efficiency.

Red Flags of Operation:
1. Significant decline in any KPI compared to the previous month.
2. Consistent negative trends across multiple metrics.
3. Failure to load metrics or error messages indicating issues with data retrieval.
4. Inability to refresh or compare metrics effectively.

Dashboard Needs:
1. Display of core operational KPIs with current values and trends.
2. Visual indicators for positive and negative trends.
3. Refresh button for real-time data updates.
4. Option to compare metrics over different time periods.
5. Clear error messages for any data loading issues.
