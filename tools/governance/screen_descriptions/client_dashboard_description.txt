List of work the user must do:
1. Monitor client data and performance metrics.
2. Review and analyze reports generated from the dashboard.
3. Interact with various features available on the dashboard.
4. Identify any issues or discrepancies in client data.
5. Communicate with team members regarding client status and updates.

Red flags of operation:
1. Delays in data loading or updates.
2. Frequent errors or crashes when accessing features.
3. Inconsistencies in displayed data compared to expected results.
4. Lack of responsiveness in the user interface.
5. Unclear error messages that do not guide the user on how to resolve issues.

What is needed on the user dashboard:
1. Real-time data updates and performance indicators.
2. Clear visualizations of client metrics (graphs, charts).
3. Notifications for any critical issues or alerts.
4. Quick access to support or help resources.
5. User-friendly navigation to access different sections of the dashboard.
