List of work the user must do:
1. Monitor key performance indicators (KPIs) relevant to the organization.
2. Review financial reports and budgets.
3. Analyze operational efficiency and productivity metrics.
4. Oversee project statuses and timelines.
5. Evaluate employee performance and engagement levels.
6. Make strategic decisions based on data insights.
7. Communicate with stakeholders and team members.

Red flags of operation:
1. Significant deviations from budgeted expenses.
2. Declining trends in key performance indicators.
3. High employee turnover rates.
4. Delays in project timelines.
5. Low customer satisfaction scores.
6. Increased operational costs without corresponding revenue growth.
7. Frequent errors or issues reported in operational processes.

What is needed on the dashboard for the user:
1. Real-time KPIs visualization (e.g., sales, expenses, profit margins).
2. Financial summaries (e.g., income statement, balance sheet).
3. Project management overview (e.g., timelines, milestones).
4. Employee performance metrics (e.g., productivity, engagement scores).
5. Alerts for any red flags or anomalies in data.
6. Interactive charts and graphs for data analysis.
7. Communication tools for stakeholder updates and feedback.
