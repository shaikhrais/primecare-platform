User Tasks:
1. Monitor live telehealth consultations.
2. Reschedule consultations as needed.
3. Update the status of consultations (e.g., Active, Finished).
4. View metrics related to telehealth consultations (e.g., active calls, upcoming consultations, completed visits).
5. Manage digital room links for consultations.

Red Flags of Operation:
1. High number of consultations marked as 'Scheduled' without being converted to 'Active'.
2. Frequent rescheduling of consultations, indicating potential issues with availability or scheduling conflicts.
3. Errors loading telehealth consults, which may indicate API issues or data retrieval problems.
4. Low number of 'Active' consultations compared to 'Scheduled', suggesting inefficiencies in consultation management.

Dashboard Requirements:
1. Display metrics for active, upcoming, and completed consultations.
2. Provide a rescheduling form for consultations.
3. Show real-time status updates for consultations.
4. Include error messages or loading indicators for better user feedback.
5. Visual representation of telehealth metrics (e.g., charts or graphs) for quick insights.
