Shareholder Responsibilities:
1. Monitor compliance and operational metrics.
2. Review logs for any discrepancies or issues.
3. Ensure timely execution of workflow scans.
4. Trigger necessary governance actions when required.
5. Maintain communication with stakeholders regarding workflow status.

Red Flags in Operations:
1. Increased error rates in API responses.
2. Delays in executing workflow scans.
3. Unusual patterns in operational logs.
4. Low clearance status or flagged exceptions.
5. High loading times or performance issues in the application.

Dashboard Requirements for Shareholders:
1. Real-time metrics on active workflow streams.
2. Clearance status indicators.
3. Operational logs with timestamps for easy tracking.
4. Telemetry charts showing performance over time.
5. Alerts for any anomalies or issues detected in the workflow.
