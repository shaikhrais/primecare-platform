User Tasks:
1. Monitor the SSO redirect process to ensure it functions correctly.
2. Verify that the redirect URL is valid and accessible.
3. Check for any errors during the SSO launch process.
4. Ensure that the user experience is smooth and that the loading indicator is displayed appropriately.
5. Collect feedback from users regarding the redirect experience.

Red Flags of Operation:
1. Frequent errors logged during the SSO launch process.
2. Users reporting delays or failures in redirection.
3. Invalid or broken redirect URLs being used.
4. Inconsistent behavior across different devices or browsers.
5. High user drop-off rates during the redirect process.

Dashboard Requirements:
1. Real-time monitoring of SSO redirect success and failure rates.
2. Error logs and alerts for any issues encountered during the redirect.
3. User feedback collection mechanism to assess the redirect experience.
4. Performance metrics, including average redirect time.
5. Statistics on the number of users redirected versus those who encountered issues.
