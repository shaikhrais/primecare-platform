User Tasks:
1. Monitor active incidents.
2. Refresh incident data.
3. Declare new incidents.
4. Join war room for specific incidents.
5. Review incident details including severity, status, title, description, and lead.

Red Flags of Operation:
1. Frequent loading errors when fetching active incidents.
2. High number of active incidents indicating potential system issues.
3. Incidents with unknown status or unassigned leads.
4. Delays in declaring new incidents.
5. Lack of engagement in war room activities.

Dashboard Needs:
1. Real-time display of active incidents with severity and status.
2. Quick access button to refresh incident data.
3. Option to declare new incidents prominently displayed.
4. Notifications for critical incidents.
5. Summary statistics of incidents (e.g., total active, resolved, and declared incidents).
