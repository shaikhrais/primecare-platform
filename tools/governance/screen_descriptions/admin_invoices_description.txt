List of work the user must do:
1. Monitor the status of invoices.
2. Review and approve or reject invoices.
3. Generate reports on invoice activities.
4. Manage user permissions related to invoice access.
5. Address any discrepancies or errors in invoices.

Red flags of operation:
1. High number of error messages when loading data.
2. Delays in loading times for invoice data.
3. Frequent crashes or unexpected behavior of the application.
4. Inconsistent data displayed on the dashboard.
5. User complaints about access issues or permissions.

What is needed on the dashboard of the user:
1. Overview of total invoices (pending, approved, rejected).
2. Quick access buttons for common actions (approve, reject, generate report).
3. Notifications for any errors or issues that need attention.
4. Visual indicators for invoice status (e.g., color-coded statuses).
5. Search and filter options for easy navigation through invoices.
