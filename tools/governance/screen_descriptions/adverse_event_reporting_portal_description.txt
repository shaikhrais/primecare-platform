User Tasks:
1. Report adverse events through the portal.
2. Review previously reported adverse events.
3. Access guidelines and resources related to adverse event reporting.
4. Submit follow-up information for existing reports.
5. Generate reports on adverse events for analysis.

Red Flags of Operation:
1. Delays in reporting or processing adverse events.
2. Incomplete or inaccurate data submissions.
3. Lack of user engagement or low reporting rates.
4. Technical issues or bugs in the portal affecting usability.
5. Insufficient training or resources for users on how to report effectively.

Dashboard Requirements:
1. Overview of reported adverse events (total count, status).
2. User engagement metrics (number of active users, frequency of reports).
3. Alerts for overdue follow-ups or pending reports.
4. Performance indicators (average time to process reports).
5. Access to resources and guidelines for users.
