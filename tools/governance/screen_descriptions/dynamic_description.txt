User Work Responsibilities:
1. Monitor the lifecycle status of projects (completed, generation, testing, backlog, research, design, legacy).
2. Update project metadata including title and feature name.
3. Review and analyze the technical manifest and development pipeline.
4. Assess platform integrity and architecture status.
5. Engage with the governance stack and audit actions.
6. Utilize the dashboard to track completion percentages and project statuses.

Red Flags of Operation:
1. Projects stuck in backlog or research phases for extended periods.
2. High percentage of projects marked as 'stubbed' indicating incomplete work.
3. Lack of updates in project metadata leading to outdated information.
4. Inconsistent or unclear status indicators on the dashboard.
5. Low completion percentages across multiple projects.
6. Delays in moving projects through the lifecycle stages.

Dashboard Requirements:
1. Visual representation of project lifecycle statuses (e.g., pie chart or progress bar).
2. Alerts for projects that are overdue or at risk of stagnation.
3. Quick access to project metadata for easy updates.
4. Summary of completion percentages for all active projects.
5. Detailed view of the technical manifest and governance stack for each project.
6. Historical data tracking to identify trends in project performance over time.
