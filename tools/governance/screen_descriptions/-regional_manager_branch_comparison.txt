User Work List:
1. Monitor branch performance metrics.
2. Compare performance across different branches.
3. Analyze trends and identify areas for improvement.
4. Generate reports based on branch comparisons.
5. Collaborate with branch managers to address performance issues.
6. Review user feedback and system errors.

Red Flags of Operation:
1. Significant discrepancies in performance metrics between branches.
2. Frequent loading errors or slow response times in the application.
3. Inconsistent data presentation or reporting.
4. High volume of user complaints or feedback regarding usability.
5. Lack of actionable insights from the data provided.

Dashboard Requirements:
1. Overview of key performance indicators (KPIs) for each branch.
2. Visual comparison charts (e.g., bar graphs, line charts) for easy analysis.
3. Alerts for any branches underperforming against set benchmarks.
4. Access to detailed reports for deeper insights.
5. User feedback section for continuous improvement suggestions.
6. Real-time data updates to ensure accuracy.
