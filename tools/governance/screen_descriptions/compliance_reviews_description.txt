List of work the user must do:
1. Review compliance data.
2. Monitor compliance metrics.
3. Identify areas of non-compliance.
4. Generate compliance reports.
5. Collaborate with team members on compliance issues.
6. Update compliance documentation as necessary.
7. Attend compliance training sessions.

Red flags of operation:
1. Frequent errors loading compliance data.
2. Delays in data processing or report generation.
3. Inconsistent compliance metrics.
4. Lack of user engagement with compliance reviews.
5. High number of unresolved compliance issues.
6. Negative feedback from users regarding the compliance process.
7. Missing or outdated compliance documentation.

What is needed on the user dashboard:
1. Overview of compliance status (e.g., compliant, non-compliant).
2. Key performance indicators (KPIs) related to compliance.
3. Alerts for any compliance issues that need immediate attention.
4. Access to recent compliance reports.
5. A summary of user activities related to compliance.
6. Links to training resources and documentation.
7. A feedback mechanism for users to report issues or suggest improvements.
