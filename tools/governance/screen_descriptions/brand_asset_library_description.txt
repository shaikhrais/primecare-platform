User Tasks:
1. View approved marketing assets.
2. Refresh the asset list.
3. Upload new assets.
4. Download existing assets.

Red Flags of Operation:
1. Slow loading times when fetching assets.
2. Frequent errors when accessing the asset list.
3. Inability to upload assets due to UI issues or backend failures.
4. Poor user experience if assets are not displayed correctly.

Dashboard Needs:
1. Asset loading status (loading, error, success).
2. Number of assets available.
3. Recent uploads and downloads activity.
4. Notifications for failed uploads or errors.
5. User engagement metrics (e.g., most downloaded assets).
