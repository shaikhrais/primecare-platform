User Work List:
1. Monitor the loading state of the Patient Charting screen.
2. Review logs for compliance and operational audits.
3. Trigger compliance scans and review results.
4. Refresh the dashboard and logs manually.
5. Execute governance actions as needed.

Red Flags of Operation:
1. Frequent network errors during compliance scans.
2. API errors indicating issues with the compliance scan process.
3. High loading times when accessing the Patient Charting screen.
4. Inconsistent log entries that may indicate operational issues.
5. Low security clearance levels or exceptions logged.

Dashboard Needs:
1. Display current loading state (loading or ready).
2. Show the title of the Patient Charting screen.
3. Provide a list of operational audit logs.
4. Include metrics for active operations and security clearance levels.
5. Present a telemetry chart for hourly core telemetry data.
6. Allow for manual refresh and execution of compliance scans.
