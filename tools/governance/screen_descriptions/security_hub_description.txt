List of work the user must do:
1. Monitor security alerts and notifications.
2. Review security logs and reports.
3. Manage user access and permissions.
4. Configure security settings and policies.
5. Respond to security incidents and breaches.
6. Conduct regular security audits and assessments.
7. Update security software and tools as needed.

Red flags of operation:
1. Frequent security alerts indicating potential breaches.
2. Unusual access patterns or unauthorized access attempts.
3. Delays in responding to security incidents.
4. Incomplete or outdated security logs.
5. Lack of user training on security best practices.
6. Non-compliance with security policies and regulations.
7. High number of unresolved security tickets.

What is needed on the user dashboard:
1. Overview of current security status and alerts.
2. Quick access to recent security incidents and responses.
3. Summary of user access and permissions.
4. Notifications for required actions or updates.
5. Visual representation of security trends and metrics.
6. Links to security policies and training resources.
7. Tools for managing and configuring security settings.
