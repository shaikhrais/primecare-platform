Infrastructure Auditor Responsibilities:
1. Conduct regular audits of infrastructure components.
2. Assess compliance with security policies and standards.
3. Evaluate system performance and capacity.
4. Identify vulnerabilities and risks in the infrastructure.
5. Review configuration management processes.
6. Monitor and analyze logs for unusual activities.
7. Ensure proper documentation of infrastructure changes.
8. Collaborate with IT teams to implement best practices.
9. Provide recommendations for improvements.
10. Prepare audit reports and present findings to stakeholders.

Red Flags of Operation:
1. Frequent system outages or downtime.
2. Unpatched vulnerabilities in critical systems.
3. Inconsistent configuration management.
4. Lack of documentation for infrastructure changes.
5. Unauthorized access attempts or security breaches.
6. Performance degradation in key services.
7. Non-compliance with regulatory requirements.
8. Insufficient monitoring and alerting mechanisms.
9. High levels of technical debt.
10. Poor communication between teams regarding infrastructure changes.

Dashboard Requirements for Infrastructure Auditor:
1. Overview of system health and uptime metrics.
2. Security compliance status and vulnerabilities.
3. Performance metrics (CPU, memory, disk usage).
4. Audit trail of changes made to the infrastructure.
5. Alerts for critical issues or anomalies.
6. Summary of recent audit findings and recommendations.
7. Visualization of infrastructure components and dependencies.
8. Historical data trends for performance and compliance.
9. Integration with logging and monitoring tools.
10. User access and activity logs for accountability.
