User Tasks:
1. View the list of OSHA incidents.
2. Refresh the incident list.
3. File a new incident report.
4. View detailed information for each incident by clicking on "View Form 301".

Red Flags of Operation:
1. Loading state takes too long, indicating potential API performance issues.
2. Frequent errors when fetching incident data, suggesting backend or network problems.
3. Lack of user feedback when filing a new report, which may lead to confusion.
4. Inconsistent data display, such as missing or incorrect incident details.

Dashboard Needs:
1. Summary of total incidents reported.
2. Quick access to file a new report.
3. Notifications for any errors or issues encountered while fetching data.
4. Filters to view incidents by date, location, or employee name.
5. Visual indicators for incidents that require urgent attention or follow-up.
