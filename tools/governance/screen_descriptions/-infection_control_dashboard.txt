List of work the user must do:
1. Monitor infection control metrics.
2. Review infection rates and trends.
3. Identify areas needing improvement.
4. Access reports on infection control compliance.
5. Collaborate with healthcare teams to implement infection control measures.

Red flags of operation:
1. Sudden spikes in infection rates.
2. Non-compliance with infection control protocols.
3. Delays in reporting or data access.
4. Lack of user engagement with the dashboard.
5. Inconsistent data updates or inaccuracies.

What is needed on the user dashboard:
1. Real-time infection rate statistics.
2. Visualizations of trends over time.
3. Alerts for critical infection control issues.
4. Access to historical data for comparison.
5. User-friendly navigation and search functionality.
6. Integration with other healthcare systems for comprehensive data.
