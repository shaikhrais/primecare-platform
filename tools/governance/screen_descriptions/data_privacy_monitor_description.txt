User Work Responsibilities:
1. Monitor data privacy metrics and compliance.
2. Investigate anomalies and alerts related to data privacy.
3. Review active data endpoints and assess risks.
4. Handle data access requests and ensure proper documentation.
5. Regularly refresh and update the dashboard for the latest metrics.

Red Flags of Operation:
1. High number of active data endpoints indicating potential exposure.
2. Increased count of high-risk anomalies suggesting security vulnerabilities.
3. A surge in data access requests that may indicate unauthorized access.
4. Frequent alerts for unusual activities that require immediate attention.
5. Delays in investigating anomalies which could lead to compliance issues.

Dashboard Requirements:
1. Real-time display of key metrics such as active data endpoints, high-risk anomalies, and data access requests.
2. Alerts section for recent anomaly notifications with actionable buttons for investigation.
3. Visual representation of risks through risk cards for quick assessment.
4. Refresh button to update metrics and ensure data accuracy.
5. Error handling to inform users of any issues loading data.
