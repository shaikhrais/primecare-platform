List of work for the User:
1. Review the data presented on the CEO Reports screen.
2. Monitor the loading state for data retrieval.
3. Address any errors that may occur during data loading.
4. Analyze the reports and insights provided in the data.
5. Provide feedback or request additional features based on the reports.

Red flags of operation:
1. Frequent loading states indicating potential performance issues.
2. Recurring errors during data loading that may suggest backend problems.
3. Lack of relevant data or insights in the reports.
4. User interface issues that hinder navigation or understanding of the reports.
5. Inconsistent data presentation that may confuse users.

What is needed on the User dashboard:
1. Summary of key metrics and insights from the reports.
2. Notifications for any errors or loading issues encountered.
3. Quick access to frequently used features or reports.
4. Visual representations of data (charts, graphs) for better understanding.
5. Feedback mechanism for users to report issues or suggest improvements.
