User Tasks:
1. Monitor the health status of external third-party services.
2. Refresh the integration health data by clicking the refresh button.
3. View logs for specific integrations by clicking the "View Logs" button.

Red Flags of Operation:
1. If the integration health data fails to load, an error message will be displayed.
2. If any integration status is not "healthy," it indicates a potential issue that needs attention.
3. High latency values may indicate performance issues with specific integrations.

Dashboard Requirements:
1. Display the health status of each integration (healthy or unhealthy).
2. Show the last sync time for each integration.
3. Provide latency metrics for each integration.
4. Include a refresh button to update the health status.
5. Allow users to view logs for each integration.
