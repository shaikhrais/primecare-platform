List of work the user must do:
1. Review compliance reports generated by the system.
2. Analyze data for any discrepancies or issues.
3. Ensure all compliance requirements are met.
4. Document findings and actions taken.
5. Communicate with relevant stakeholders regarding compliance status.

Red flags of operation:
1. Frequent errors or failures in loading compliance data.
2. Delays in report generation.
3. Inconsistent data across different reports.
4. Lack of user feedback or engagement with the compliance reports.
5. High number of unresolved compliance issues.

What we need on the user dashboard:
1. Summary of compliance status (e.g., compliant, non-compliant).
2. Notifications for any compliance issues or deadlines.
3. Quick access to recent compliance reports.
4. Visual indicators for trends in compliance over time.
5. Links to resources or guidelines for improving compliance.
