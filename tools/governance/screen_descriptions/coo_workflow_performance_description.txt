User Tasks:
1. Monitor workflow performance metrics.
2. Identify bottlenecks in the workflow.
3. Review completed tasks and pending tasks.
4. Analyze user feedback and operational efficiency.
5. Generate reports on workflow performance.

Red Flags of Operation:
1. Increased loading times for data retrieval.
2. Frequent error messages during data loading.
3. Significant discrepancies in task completion rates.
4. User complaints regarding workflow inefficiencies.
5. Lack of updates or stale data on the dashboard.

Dashboard Requirements:
1. Real-time performance metrics display.
2. Visual indicators for bottlenecks (e.g., red flags).
3. Task completion statistics (completed vs. pending).
4. User feedback section for operational insights.
5. Downloadable reports for performance analysis.
