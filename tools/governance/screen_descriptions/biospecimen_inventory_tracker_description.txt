User Tasks:
1. Track biospecimen inventory levels.
2. Update biospecimen information (add, edit, delete).
3. Search and filter biospecimens based on various criteria.
4. Generate reports on biospecimen usage and availability.
5. Monitor expiration dates and notify when specimens are nearing expiration.
6. Collaborate with team members on biospecimen management.

Red Flags of Operation:
1. Inconsistent data entry leading to inaccurate inventory counts.
2. Delays in updating biospecimen information.
3. Lack of notifications for expired or soon-to-expire specimens.
4. Difficulty in searching or filtering biospecimens effectively.
5. Poor user interface leading to user frustration.
6. Insufficient reporting capabilities to analyze inventory trends.

Dashboard Needs:
1. Real-time inventory levels of biospecimens.
2. Alerts for low stock and expiration dates.
3. Quick access to recent updates and changes made to the inventory.
4. Search bar for easy filtering of biospecimens.
5. Visual representation of inventory trends (graphs/charts).
6. User activity log to track changes made by team members.
