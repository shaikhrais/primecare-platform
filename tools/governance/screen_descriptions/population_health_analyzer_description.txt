User Work List:
1. View population health data.
2. Refresh data by clicking the refresh button.
3. Export cohort data using the export button.
4. Analyze demographics and risk stratification.
5. Review cohort details including name, population size, and risk level.
6. Interpret geospatial heatmap data (placeholder).

Red Flags of Operation:
1. Data loading failures indicated by error messages.
2. Long loading times when fetching population health data.
3. Inconsistent or missing data in cohort details.
4. High-risk cohorts should be clearly highlighted for immediate attention.
5. User interface issues that may hinder data interpretation.

Dashboard Needs:
1. Real-time data loading status (loading, error, success).
2. Visual representation of demographics and risk stratification.
3. Clear indicators for high-risk cohorts.
4. Export functionality for cohort data.
5. Geospatial heatmap for visual analysis of population health.
6. User-friendly navigation and interaction elements.
