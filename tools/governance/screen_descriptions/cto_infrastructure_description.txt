User Work List:
1. Monitor the status of the CtoInfrastructure.
2. Review the data presented on the dashboard.
3. Identify any errors or issues during loading.
4. Ensure the application is functioning as intended.
5. Provide feedback on the user interface and experience.

Red Flags of Operation:
1. Frequent loading errors or timeouts.
2. Inconsistent data displayed on the dashboard.
3. Lack of responsiveness in the user interface.
4. High error rates when fetching data.
5. User complaints regarding functionality or usability.

Dashboard Requirements:
1. Real-time status indicators for CtoInfrastructure.
2. Error logs and alerts for any issues encountered.
3. Performance metrics (loading times, error rates).
4. User feedback section for suggestions and issues.
5. Visual representations of data for easier analysis.
