Caregiver Tasks Responsibilities:
1. Conduct compliance scans.
2. Monitor operational audit logs.
3. Manage active operations.
4. Ensure security clearance levels are maintained.
5. Refresh dashboard telemetry.
6. Trigger state actions as required.

Red Flags of Operation:
1. High number of errors during compliance scans.
2. Low security clearance levels.
3. Decrease in active operations.
4. Inconsistent telemetry data.
5. Delays in refreshing logs or dashboard data.

Dashboard Requirements for Caregiver:
1. Title and description of the dashboard.
2. Metrics for active operations and security clearance.
3. Telemetry chart for hourly data.
4. Operational audit logs display.
5. Buttons for executing compliance scans and refreshing data.
6. Loading indicators for ongoing processes.
