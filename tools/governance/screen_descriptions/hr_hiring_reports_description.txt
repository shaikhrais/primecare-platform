List of work the user must do:
1. Review hiring reports.
2. Analyze data trends in hiring.
3. Identify areas for improvement in the hiring process.
4. Generate reports for stakeholders.
5. Monitor key performance indicators (KPIs) related to hiring.

Red flags of operation:
1. High turnover rates in newly hired employees.
2. Long time-to-hire metrics.
3. Low candidate satisfaction scores.
4. Discrepancies in hiring data.
5. Frequent changes in hiring criteria or processes.

What we need on the dashboard for the user:
1. Overview of current hiring metrics (e.g., time-to-hire, turnover rates).
2. Visualizations of hiring trends over time.
3. Alerts for any red flags identified in the hiring process.
4. Quick access to generate detailed reports.
5. User feedback section for continuous improvement suggestions.
