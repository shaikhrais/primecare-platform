User Tasks:
1. Review pending manager certifications.
2. Certify access for employees.
3. Revoke selected privileges for employees.
4. Refresh the access reviews list.

Red Flags of Operation:
1. Loading errors when fetching access reviews.
2. Delays in loading data, indicating potential performance issues.
3. Inability to revoke or certify access due to unresponsive buttons.
4. Missing or incomplete data in access reviews.

Dashboard Needs:
1. Overview of pending certifications.
2. Quick access to revoke or certify actions.
3. Notifications for any errors or loading issues.
4. Summary of total access reviews and their statuses (pending, certified, revoked).
