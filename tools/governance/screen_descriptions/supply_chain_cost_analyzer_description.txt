User Tasks:
1. Analyze procurement spending by category.
2. Refresh data to get the latest cost information.
3. Manage vendors through the provided button.

Red Flags of Operation:
1. Data loading failures, indicated by error messages.
2. Categories with a variance greater than budget, signaling overspending.
3. Inability to refresh data, which may indicate issues with the API or network.

Dashboard Needs:
1. Display of procurement spending by category.
2. Visual indicators for budget vs. actual spending.
3. Clear indication of variance and whether it is over or under budget.
4. Option to manage vendors directly from the dashboard.
