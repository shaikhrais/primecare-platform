User Tasks:
1. Monitor the incident report dashboard for key performance indicators.
2. Trigger compliance scans to ensure governance standards are met.
3. Review operational audit logs for any discrepancies or issues.
4. Refresh the dashboard to synchronize telemetry data.
5. Execute state actions as required by governance protocols.

Red Flags of Operation:
1. High loading times during compliance scans may indicate performance issues.
2. Frequent API errors during scans could suggest connectivity or server problems.
3. Logs showing repeated network errors may indicate underlying infrastructure issues.
4. Low values in telemetry charts could signal operational inefficiencies.
5. Any discrepancies in operational audit logs should be investigated immediately.

Dashboard Requirements:
1. Display current loading status and error messages clearly.
2. Show key performance indicators such as active operations and security clearance levels.
3. Provide a real-time telemetry chart for monitoring operational performance.
4. Include a section for operational audit logs with timestamps and severity levels.
5. Offer buttons for executing compliance scans and refreshing data, with loading indicators.
