List of work the user must do:
1. Access the Family Emergency Contacts screen.
2. Review the displayed information regarding family emergency contacts.
3. Monitor the loading state for any delays in data retrieval.
4. Handle any errors that may occur during data loading.

Red flags of operation:
1. Prolonged loading times indicating potential performance issues.
2. Frequent error messages suggesting instability in data retrieval.
3. Lack of data displayed when the screen is accessed, indicating possible backend issues.
4. Unresponsive UI elements that may hinder user interaction.

What is needed on the dashboard of the user:
1. A summary of the current status of family emergency contacts.
2. Notifications for any errors or issues encountered during data loading.
3. Performance metrics such as loading times and error rates.
4. A clear call-to-action for users to add or update emergency contacts if necessary.
