User Tasks:
1. Monitor system capacity metrics including compute nodes, database storage, and network bandwidth.
2. Refresh capacity data to ensure up-to-date information.
3. Analyze the 6-month resource projection for planning purposes.
4. Identify trends in resource usage to make informed decisions.

Red Flags of Operation:
1. Compute nodes usage exceeding 85% indicates potential overload.
2. Database storage usage above 85% suggests imminent capacity issues.
3. Network bandwidth usage over 70% may lead to performance degradation.
4. Frequent errors in loading capacity data could indicate API issues or system instability.

Dashboard Requirements:
1. Real-time display of compute nodes, database storage, and network bandwidth usage.
2. Visual indicators (e.g., color-coded progress bars) for usage levels.
3. Refresh button for manual data updates.
4. 6-month resource projection chart for forecasting future needs.
5. Error messages for failed data loads to inform users of issues.
