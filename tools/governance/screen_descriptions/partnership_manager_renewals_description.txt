User Tasks:
1. Monitor partnership renewals.
2. Review renewal statuses and deadlines.
3. Communicate with partners regarding renewal terms.
4. Update partnership details as necessary.
5. Analyze renewal trends and performance metrics.

Red Flags of Operation:
1. Delayed responses from partners.
2. High number of overdue renewals.
3. Frequent errors in partnership details.
4. Lack of engagement from partners.
5. Inconsistent data reporting.

Dashboard Requirements:
1. Overview of upcoming renewals with deadlines.
2. Alerts for overdue renewals.
3. Performance metrics (e.g., renewal rates, partner engagement).
4. Communication logs with partners.
5. Quick access to edit partnership details.
