User Tasks:
1. Monitor community outreach partnerships.
2. Analyze partnership effectiveness.
3. Engage with community stakeholders.
4. Update partnership information.
5. Report on outreach activities and outcomes.

Red Flags of Operation:
1. Delayed response times from partners.
2. Low engagement rates in community activities.
3. Inconsistent data reporting from outreach efforts.
4. Lack of communication from stakeholders.
5. Negative feedback from community members.

Dashboard Needs:
1. Partnership performance metrics (engagement rates, response times).
2. Real-time updates on outreach activities.
3. Visual representation of partnership effectiveness (charts/graphs).
4. Alerts for any red flags identified.
5. Feedback section for community input and concerns.
