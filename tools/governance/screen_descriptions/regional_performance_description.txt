User Work List:
1. Monitor regional performance metrics.
2. Analyze data trends and patterns.
3. Identify areas for improvement in regional operations.
4. Collaborate with regional teams to implement changes.
5. Report findings and recommendations to management.

Red Flags of Operation:
1. Significant discrepancies in performance metrics across regions.
2. Consistent delays in data loading or processing.
3. Frequent errors or crashes when accessing the performance screen.
4. Lack of engagement or feedback from regional teams.
5. Inability to track changes or improvements over time.

Dashboard Requirements:
1. Real-time performance metrics for each region.
2. Visualizations (charts/graphs) to identify trends.
3. Alerts for significant deviations from expected performance.
4. User feedback section for continuous improvement.
5. Historical data comparison to track progress over time.
