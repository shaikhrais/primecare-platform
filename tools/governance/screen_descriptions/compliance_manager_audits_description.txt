User Tasks:
1. Review compliance audit reports.
2. Track audit completion status.
3. Identify non-compliance issues.
4. Generate compliance reports.
5. Communicate with team members regarding audit findings.
6. Update compliance documentation as needed.
7. Monitor deadlines for audit submissions.

Red Flags of Operation:
1. Delays in audit report submissions.
2. High number of non-compliance issues identified.
3. Lack of communication among team members.
4. Incomplete or outdated compliance documentation.
5. Frequent errors in generated compliance reports.
6. Low user engagement with the compliance dashboard.

Dashboard Requirements:
1. Overview of audit completion status (percentage completed).
2. List of recent compliance issues with details.
3. Notifications for upcoming deadlines.
4. Summary of team communication regarding audits.
5. Access to generate and download compliance reports.
6. Visual representation of trends in compliance over time.
7. Quick links to update documentation and submit audits.
