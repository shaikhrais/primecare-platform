List of work for the user:
1. Review financial data presented on the Franchise Owner Financial Snapshot screen.
2. Monitor key performance indicators (KPIs) related to franchise operations.
3. Analyze trends in revenue and expenses.
4. Identify areas for cost reduction or revenue enhancement.
5. Ensure data accuracy and report any discrepancies.

Red flags of operation:
1. Significant fluctuations in revenue or expenses.
2. Consistent underperformance against KPIs.
3. Delays in data updates or loading times.
4. Frequent error messages or crashes when accessing financial data.
5. Lack of clarity in financial reporting.

Dashboard needs for the user:
1. Real-time financial metrics (revenue, expenses, profit margins).
2. Visual representations of data (charts, graphs).
3. Alerts for significant changes or anomalies in financial data.
4. Historical data comparison for trend analysis.
5. User-friendly navigation to access different financial reports easily.
