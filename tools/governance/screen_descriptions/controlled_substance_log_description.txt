User Tasks:
1. Access the Controlled Substance Log screen.
2. View the list of controlled substances.
3. Add new entries for controlled substances.
4. Edit existing entries.
5. Delete entries if necessary.
6. Search for specific controlled substances.
7. Generate reports based on the log data.
8. Ensure compliance with regulations.

Red Flags of Operation:
1. Inability to add or edit entries due to system errors.
2. Slow response times when accessing the log.
3. Missing or incomplete data in the log entries.
4. Unauthorized access attempts to the log.
5. Lack of search functionality or poor search results.
6. Inconsistent data formats across entries.
7. Failure to generate reports or incorrect report data.
8. Non-compliance alerts or warnings.

Dashboard Requirements:
1. Overview of total entries in the controlled substance log.
2. Quick access buttons for adding, editing, and deleting entries.
3. Search bar for easy lookup of substances.
4. Alerts for any compliance issues or red flags.
5. Recent activity log showing the latest changes made.
6. Performance metrics such as response times and error rates.
7. Option to generate reports directly from the dashboard.
8. User access logs to monitor who accessed the log and when.
