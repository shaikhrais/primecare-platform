List of work the user must do:
1. Monitor compliance credentials of team members.
2. Update and track credential statuses.
3. Generate reports on compliance metrics.
4. Review alerts for expired or expiring credentials.
5. Ensure all required credentials are obtained and maintained.

Red flags of operation:
1. Frequent errors in loading compliance data.
2. Delays in updating credential statuses.
3. High number of expired credentials.
4. Lack of user engagement with the dashboard.
5. Inconsistent reporting metrics.

What is needed on the user dashboard:
1. Overview of current compliance status.
2. Alerts for upcoming credential expirations.
3. Quick access to update credential information.
4. Visual representation of compliance metrics (charts/graphs).
5. Historical data on compliance trends.
6. User activity logs for accountability.
