User Tasks:
1. Monitor deployment statuses and verify end-to-end checks.
2. Review the summary of tracked applications, online deployments, and verified checks.
3. Access detailed logs for each deployment.
4. Launch live links for deployed applications.
5. Identify and address any deployment errors or issues.

Red Flags of Operation:
1. High number of deployments with a status other than 'success'.
2. Low count of verified end-to-end checks compared to total deployments.
3. Frequent errors loading deployment data.
4. Unverified deployments that may indicate potential issues.
5. Delays in loading deployment registries or logs.

Dashboard Requirements:
1. Summary cards displaying:
   - Total number of tracked applications.
   - Number of successful deployments.
   - Number of verified end-to-end checks.
2. List of deployments with:
   - Status indicators (success or failure).
   - Platform type (web or mobile).
   - Verification status (verified or unchecked).
   - Live link button for quick access.
   - Log button to view detailed logs for each deployment.
3. Loading indicators for data retrieval processes.
4. Error messages for any issues encountered during data loading.
