User Tasks:
1. Review and analyze potential sites for territory expansion.
2. Gather data on site demographics, accessibility, and competition.
3. Collaborate with team members to evaluate site options.
4. Make recommendations based on data analysis.
5. Monitor progress and outcomes of selected sites.
6. Update the dashboard with relevant metrics and insights.

Red Flags of Operation:
1. Delays in data retrieval or analysis.
2. Inconsistent data quality or accuracy.
3. Lack of collaboration or communication among team members.
4. High turnover of site options without clear rationale.
5. Failure to meet project deadlines or milestones.
6. Insufficient tracking of site performance metrics.

Dashboard Needs:
1. Visual representation of site performance metrics (e.g., sales, foot traffic).
2. Real-time data updates on site analysis.
3. Collaboration tools for team communication.
4. Alerts for any red flags identified in site performance.
5. Historical data comparison for informed decision-making.
6. User-friendly interface for quick access to critical information.
