User Tasks:
1. View the staff utilization heatmap to assess resource allocation.
2. Monitor burnout indicators for staff.
3. Refresh the utilization data by clicking the refresh button.
4. Adjust shifts using the provided button.

Red Flags of Operation:
1. High utilization percentages in departments, indicating potential burnout.
2. Departments marked as "High Risk" due to excessive utilization.
3. Errors in loading data, which may indicate issues with data retrieval or API.

Dashboard Requirements:
1. A visual representation of staff utilization (heatmap).
2. List of high-risk departments with utilization percentages.
3. Refresh button to update data.
4. Button to adjust shifts for better resource management.
5. Error messages displayed clearly if data fails to load.
