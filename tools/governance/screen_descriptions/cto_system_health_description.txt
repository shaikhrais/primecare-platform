User Work List:
1. Monitor system health metrics.
2. Identify and address any operational red flags.
3. Review system performance data regularly.
4. Ensure timely updates and maintenance of the system.
5. Collaborate with the development team for any issues.
6. Provide feedback for system improvements.

Red Flags of Operation:
1. Frequent system errors or crashes.
2. Slow response times or performance degradation.
3. Unusual spikes in resource usage (CPU, memory).
4. Inconsistent data or reporting anomalies.
5. Lack of timely updates or maintenance.
6. User complaints or feedback indicating issues.

Dashboard Requirements for User:
1. Real-time system health metrics display.
2. Alerts for any operational red flags.
3. Performance trend graphs over time.
4. Error logs and reporting section.
5. Maintenance schedule and update notifications.
6. User feedback section for continuous improvement.
