List of work the user must do:
1. Monitor system performance metrics.
2. Manage user accounts and permissions.
3. Review and respond to system alerts and notifications.
4. Conduct regular system audits and compliance checks.
5. Update and maintain software and hardware inventory.
6. Provide technical support to users.
7. Analyze system usage data for optimization.
8. Implement security measures and protocols.

Red flags of operation:
1. Frequent system downtimes or outages.
2. Unresolved user support tickets piling up.
3. High number of security alerts or breaches.
4. Inconsistent system performance metrics.
5. Lack of compliance with audit requirements.
6. Delays in software updates or patches.
7. User complaints about access issues or permissions.

What is needed on the dashboard for the user:
1. Real-time system performance metrics (CPU, memory usage, etc.).
2. User account management tools.
3. Alerts and notifications section for system issues.
4. Audit and compliance status indicators.
5. Software and hardware inventory overview.
6. Support ticket management interface.
7. Security status and incident reports.
8. Usage analytics for system optimization.
