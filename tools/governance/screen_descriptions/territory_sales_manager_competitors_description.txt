User Tasks:
1. Monitor competitor activities within the territory.
2. Analyze sales data and trends related to competitors.
3. Update and maintain competitor profiles.
4. Collaborate with the sales team to strategize against competitors.
5. Generate reports on competitor performance.

Red Flags of Operation:
1. Inconsistent data updates leading to outdated competitor information.
2. Delays in loading data or screen, indicating potential performance issues.
3. Frequent errors when fetching competitor data, suggesting backend or API problems.
4. Lack of user engagement or feedback on the screen's functionality.
5. High bounce rates from users navigating away from the screen quickly.

Dashboard Requirements:
1. Real-time competitor activity feed.
2. Visual analytics on sales performance against competitors.
3. Alerts for significant changes in competitor strategies or market presence.
4. User feedback section for continuous improvement.
5. Quick access buttons for updating competitor information and generating reports.
