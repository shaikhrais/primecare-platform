User Work Tasks:
1. View the list of tasks assigned to them.
2. Update the status of tasks (e.g., complete, in progress).
3. Add new tasks if permitted.
4. Remove or archive completed tasks.
5. Filter tasks based on status or priority.
6. Access detailed information about each task.

Red Flags of Operation:
1. Slow loading times when accessing the task list.
2. Inconsistent task status updates.
3. Difficulty in adding or removing tasks.
4. Lack of notifications for task deadlines or updates.
5. Unclear task descriptions or missing information.
6. User interface elements that are not responsive or intuitive.

Dashboard Requirements for User:
1. Overview of total tasks (completed, in progress, pending).
2. Quick access buttons for adding, updating, or removing tasks.
3. Visual indicators for task priority and deadlines.
4. Notifications or alerts for upcoming deadlines.
5. Search and filter options for easy navigation.
6. Summary of user performance (e.g., tasks completed over time).
