User Tasks:
1. View the list of journal club topics.
2. Refresh the topic list.
3. Create a new discussion topic.
4. Read and discuss existing topics.

Red Flags of Operation:
1. Loading state takes too long, indicating potential performance issues.
2. Frequent errors when fetching topics, suggesting API reliability problems.
3. Lack of user engagement metrics (e.g., low comments or likes on topics).
4. Inconsistent UI/UX, which may confuse users.

Dashboard Needs:
1. Overview of total topics, comments, and likes.
2. Recent activity feed showing new topics and discussions.
3. Performance metrics (loading times, error rates).
4. User engagement statistics (most discussed topics, active users).
5. Notifications for new comments or replies on topics the user is following.
