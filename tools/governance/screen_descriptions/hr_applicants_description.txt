User Work List:
1. Manage institutional settings.
2. Track real-time clinical workflows.
3. Verify live compliance standing.
4. Monitor operational status and metrics.
5. Conduct verification audits.
6. Submit secure operational event logs.

Red Flags of Operation:
1. Operational Status not marked as ACTIVE.
2. SLA uptime drops below acceptable levels (e.g., below 99.98%).
3. Verification audits show any compliance issues.
4. Significant drops in hourly transaction flow.
5. Delays or failures in submitting secure operational event logs.

Dashboard Needs:
1. Clear display of operational status and SLA uptime.
2. Compliance status with alerts for any issues.
3. Real-time transaction flow metrics.
4. Easy access to submit operational event logs.
5. Historical data trends for audits and compliance checks.
