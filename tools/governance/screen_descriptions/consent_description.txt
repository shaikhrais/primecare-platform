User Work List:
1. Log in to the PrimeCare Identity Portal.
2. Select a preferred language if prompted.
3. Review consent information on the consent screen.
4. Navigate to the success screen after authentication.
5. Sign out when finished.

Red Flags of Operation:
1. User is unable to log in due to incorrect credentials.
2. Language selection is skipped, leading to confusion.
3. Consent screen does not display properly or is missing information.
4. User is redirected to the login screen unexpectedly.
5. Session token is not generated or displayed correctly.

Dashboard Needs:
1. User authentication status (logged in/out).
2. Current selected language.
3. Consent status (accepted/rejected).
4. Session token visibility (with security considerations).
5. Notifications for any errors or required actions (e.g., re-login).
