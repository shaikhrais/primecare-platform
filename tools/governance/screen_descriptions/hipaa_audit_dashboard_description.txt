User Tasks:
1. Review PHI access logs for compliance.
2. Identify any potential violations of HIPAA regulations.
3. Refresh the audit logs to get the latest data.
4. Export the audit report for further analysis or record-keeping.

Red Flags of Operation:
1. Presence of violation flags in access logs.
2. Unusual access patterns or actions that deviate from normal behavior.
3. Access to PHI by unauthorized users or outside of normal business hours.
4. High frequency of access requests for specific patients or resources.

Dashboard Requirements:
1. Display a list of PHI access logs with user details, actions, resources accessed, and timestamps.
2. Highlight any logs that indicate violations with visual cues (e.g., color coding).
3. Provide a refresh button to update the logs in real-time.
4. Include an export button to download the audit report in a suitable format.
5. Show loading indicators and error messages for better user experience.
