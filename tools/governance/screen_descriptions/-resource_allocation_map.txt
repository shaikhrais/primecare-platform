User Work List:
1. Monitor resource allocation across different regions.
2. Refresh the resource allocation data using the refresh button.
3. Analyze the utilization levels of resources in various regions.
4. Identify regions with high, medium, and low resource utilization.
5. Review the geospatial mapping component for visual representation of resource distribution.

Red Flags of Operation:
1. High utilization scores (above 80) may indicate resource strain or over-allocation.
2. Low utilization scores (below 50) may suggest under-utilization of resources.
3. Errors in loading data should be addressed immediately to ensure accurate resource tracking.
4. Inconsistent data across regions may indicate issues in data collection or reporting.

Dashboard Needs:
1. Real-time updates on resource allocation.
2. Visual indicators for resource utilization (e.g., color-coded scores).
3. Error notifications for failed data loads.
4. A summary of resource distribution by region.
5. Historical data trends for resource utilization over time.
