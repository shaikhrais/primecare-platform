User Work List:
1. Monitor total impressions.
2. Track website visits.
3. Analyze leads generated.
4. Review appointments booked.
5. Evaluate conversion rate.
6. Refresh data as needed.

Red Flags of Operation:
1. Significant drop in total impressions.
2. Low website visits compared to impressions.
3. Decrease in leads generated.
4. Fewer appointments booked relative to leads.
5. Declining conversion rate.

Dashboard Needs:
1. Real-time metrics for each stage of the funnel.
2. Visual representation of data (graphs/charts).
3. Alerts for any significant changes or drops in metrics.
4. Historical data comparison for trend analysis.
5. Option to refresh data manually.
