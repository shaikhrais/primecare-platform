User Tasks:
1. Run compliance scan.
2. Trigger state action.
3. Manually refresh logs and telemetry.
4. Review operational audit logs.
5. Monitor key performance indicators and telemetry data.

Red Flags of Operation:
1. API errors during compliance scan.
2. Network errors when attempting to run scans.
3. Long loading times when executing operations.
4. Inconsistent or missing logs in the operational audit.
5. Low performance indicators or unexpected trends in telemetry data.

Dashboard Requirements:
1. Title and description of the assessment control center.
2. Key performance indicators (e.g., active operations, security clearance).
3. Telemetry chart displaying hourly core telemetry data.
4. Operational audit logs with timestamps and details.
5. Buttons for executing scans and refreshing logs, with loading indicators.
