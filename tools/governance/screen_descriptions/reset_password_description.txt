User Work List:
1. Enter a new password in the "NEW PASSWORD" field.
2. Confirm the new password in the "CONFIRM PASSWORD" field.
3. Submit the new password by clicking the "UPDATE PASSWORD" button.

Red Flags of Operation:
1. If the new password and confirm password fields do not match, an error message should be displayed.
2. If the password update process takes too long, the user may become frustrated.
3. If the user does not receive feedback after submitting (e.g., success or error message), it may lead to confusion.

Dashboard Needs:
1. Display the current state of the password reset process (loading, success, error).
2. Show error messages clearly if the password criteria are not met or if submission fails.
3. Provide a success message upon successful password update.
4. Track user interactions for analytics (e.g., how many users successfully reset their passwords).
