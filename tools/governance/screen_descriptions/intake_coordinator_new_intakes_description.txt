List of work for the User:
1. Monitor new intakes and ensure all necessary information is collected.
2. Review and validate the data submitted by new intakes.
3. Communicate with relevant stakeholders regarding the status of new intakes.
4. Address any issues or discrepancies in the intake process.
5. Update the system with any changes or additional information related to intakes.
6. Generate reports on intake metrics and performance.

Red flags of operation:
1. High error rates in submitted intake data.
2. Delays in processing new intakes.
3. Lack of communication from stakeholders regarding intake status.
4. Incomplete or missing information in intake submissions.
5. Frequent system errors or crashes during the intake process.

Dashboard needs for the User:
1. Overview of current new intakes and their statuses.
2. Metrics on intake processing times and error rates.
3. Alerts for any discrepancies or issues that need immediate attention.
4. Communication tools for reaching out to stakeholders.
5. Reporting features for analyzing intake trends and performance over time.
