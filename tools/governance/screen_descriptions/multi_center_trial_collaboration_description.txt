User Tasks:
1. Collaborate with multiple centers for trial management.
2. Input and update trial data.
3. Monitor trial progress and outcomes.
4. Communicate with team members across centers.
5. Access and analyze trial-related reports and metrics.

Red Flags of Operation:
1. Delays in data entry or updates from any center.
2. Inconsistent data across different centers.
3. Lack of communication or response from team members.
4. Low engagement or participation from centers.
5. High error rates in trial data submissions.

Dashboard Requirements:
1. Overview of trial progress across all centers.
2. Real-time data updates and notifications.
3. Communication logs and response times.
4. Performance metrics for each center.
5. Alerts for any red flags identified in operations.
