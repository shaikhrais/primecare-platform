List of work the user must do:
1. Access the Customer Support Templates screen.
2. Review the available customer support templates.
3. Utilize the templates for customer interactions.
4. Provide feedback on template effectiveness.
5. Report any issues or errors encountered.

Red flags of operation:
1. Slow loading times when accessing the templates.
2. Frequent errors displayed when trying to load features.
3. Lack of user engagement or feedback on templates.
4. Inconsistent template performance across different devices.
5. High number of support tickets related to template usage.

What is needed on the user dashboard:
1. Overview of available customer support templates.
2. Performance metrics of each template (e.g., usage frequency, feedback ratings).
3. Notifications for updates or new templates added.
4. Quick access to report issues or provide feedback.
5. Visual indicators for template effectiveness (e.g., success rates, user satisfaction).
