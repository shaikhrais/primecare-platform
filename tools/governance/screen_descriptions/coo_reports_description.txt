List of work for the user:
1. Monitor the status of reports generated by the COO.
2. Analyze data presented in the reports for decision-making.
3. Identify trends and patterns in operational performance.
4. Review any errors or issues highlighted in the reports.
5. Provide feedback or suggestions based on report findings.

Red flags of operation:
1. Frequent errors or failures in report generation.
2. Inconsistent data or discrepancies in report results.
3. Delays in report availability or loading times.
4. Lack of actionable insights from the reports.
5. User complaints or difficulties in navigating the report interface.

Dashboard needs for the user:
1. Real-time status updates on report generation.
2. Visualizations of key metrics and trends.
3. Alerts for any operational issues or anomalies.
4. User-friendly navigation to access different reports.
5. Feedback mechanism for users to report issues or suggest improvements.
