Red Flags of Operation:
1. High number of flagged conversations indicating potential issues with the bot's responses.
2. Frequent errors when loading audits, suggesting API or data issues.
3. Low safety scores on conversations, indicating inadequate responses.
4. User feedback indicating dissatisfaction with bot responses.

Dashboard Needs:
1. Overview of total audits and flagged conversations.
2. Metrics on safety scores and trends over time.
3. Quick access to the most recent flagged conversations.
4. Search functionality for transcripts.
5. Buttons for approving and flagging conversations easily accessible.
