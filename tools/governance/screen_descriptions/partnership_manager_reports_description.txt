User Tasks:
1. Monitor partnership performance metrics.
2. Generate reports on partnership activities.
3. Analyze data for insights on partnership effectiveness.
4. Identify potential areas for improvement in partnerships.
5. Communicate findings with stakeholders.

Red Flags of Operation:
1. Inconsistent data reporting or discrepancies in metrics.
2. Delays in report generation or data retrieval.
3. Lack of user engagement with the dashboard.
4. Frequent errors or crashes when accessing reports.
5. Negative feedback from stakeholders regarding partnership outcomes.

Dashboard Requirements:
1. Real-time partnership performance metrics.
2. Visualizations for data trends and comparisons.
3. Alerts for any anomalies or red flags in partnership data.
4. User-friendly navigation to access different reports.
5. Option to export reports in various formats (e.g., PDF, CSV).
6. Feedback mechanism for users to report issues or suggest improvements.
